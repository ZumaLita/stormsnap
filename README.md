# StormSnap

Hourly family snaps: back camera + front camera, every hour from 8u to 21u. Snapping is optional.

- Android APK: built by GitHub Actions on every push to `main` (see Releases).
- Web app: Vercel (`npx expo export -p web` → `dist`).
- Backend: Appwrite Cloud (Frankfurt), project `StormSnap`.
